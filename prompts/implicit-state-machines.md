# Implicit state machines

Use when an app tracks the status of something (a request, an upload, a session, a form) through loose booleans,
nullable fields, or string checks spread across files, and you want each one made an explicit state machine.

```
Find all of the implicit state machines in my app. Make the best decision that will elevate all three: the user experience (UX), developer experience (DX), and agent experience (AX) always, without breaking anything
```
